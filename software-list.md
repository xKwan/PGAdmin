## Commands

Run from the repository root in Windows PowerShell 5.1 or later:

| Task | Command |
|---|---|
| Install or verify everything (uses pinned versions) | `powershell -ExecutionPolicy Bypass -File scripts\toolchain\Install-Toolchain.ps1` |
| Install with no network access (air-gapped) | `... Install-Toolchain.ps1 -Offline` (needs `tools\downloads\` and `toolchain\software.lock.json`) |
| Move to newer versions within the manifest's version spec | `... Install-Toolchain.ps1 -Update` |
| Use the tools in the current PowerShell session only | `. .\scripts\toolchain\Use-Toolchain.ps1` |
| Remove one package | `... scripts\toolchain\Uninstall-Toolchain.ps1 -Name maven` |
| Remove everything the project installed, including downloads and the Maven repository | `... scripts\toolchain\Uninstall-Toolchain.ps1 -All -Purge` |

For an air-gapped machine, copy the repository plus `tools\downloads\` and the dependency caches (`tools\m2\`, `tools
pm-cache\`) once they exist, then run the offline install.
